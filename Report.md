# Data Science Internship Assignment - Shipment Delay Analysis

The analysis shows that shipment lateness is an operational risk, with approximately 24.5% of training shipments being late. The "never late" baseline already achieves about 75.5% accuracy, showing why accuracy alone is not sufficient for evaluating a late-delivery model.

## Top drivers of lateness

- **Delivery commitment**
- **Distance**
- **Dispatch Timing**

## Model / Evaluation Limitation

The analysis was not fully completed within the available time, so a final production model performance should not be claimed as validated.
